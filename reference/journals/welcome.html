Warcraft 5e (WC5E)

This is a beta, in active development. The content is complete but still being curated, so feel free to lend us a hand in that by checking it out and reporting issues (see bottom of document).

A Foundry VTT module for World of Warcraft using the community Warcraft 5e (WC5E) conversion on the dnd5e system.

The goal is a complete WC5E module: everything from the WC5E project books, all properly ported to Foundry. Monsters, spells, items and the full set of player options are in, including backgrounds and class spell lists (see Roadmap).

What's inside

  • WC5E Monsters: 420 NPC actors (Manual of Monsters + WIP drafts), organised into folders by creature type.
  • WC5E Items: 21 Warcraft weapons & gear: firearms, exotic weapons, shields, ammunition, and adventuring gear.
  • WC5E Spells: A full 100+ WC5E custom spell list, foldered by level.
  • Player Options: 12 classes, 36 subclasses, 28 races, class features, feats, equipment and summons, with dnd5e advancement configured. Drag a class and a race onto a blank sheet and level up.

How to use

  • Open the Compendium Packs sidebar tab → drag monsters onto the canvas and items/spells onto character sheets.
  • Spellcasters have a class spell list (see WC5E Class Spell Lists). If you use a guided character-builder module, point its spell-list setting at that compendium.
  • Some monster spells and abilities reference non-SRD spells that can't be bundled, so those stay listed as text. If you own that content, use Settings → Module Settings → Auto-Assign Spells. It searches the compendiums you select, adds the spells it finds to WC5E monsters and class spell lists, and tells you what it couldn't find. It never removes or overwrites content. You can run it more than once, and it remembers your compendium selection. Run it again after updating the module.

If you find a problem, open an issue on GitHub or join the WC5E Discord and report it in the #bug-reporting channel.
